Ketika grafik penyimpanan internal smartphone menunjukkan pemakaian 95% hingga muncul peringatan "Ruang penyimpanan hampir habis" padahal Anda hanya menginstal sedikit aplikasi, ruang memori tersebut sebenarnya tersedot oleh kategori File Lainnya (Other / System Data). Di sistem Android maupun iOS, pembengkakan ini bersumber dari empat lokasi tersembunyi: tumpukan database cadangan lokal WhatsApp (msgstore), folder Sampah (Trash) Galeri yang menahan file selama 30 hari, cache video aplikasi pendek (TikTok, Instagram, Telegram), serta indeks .thumbnails yang membengkak.

⚡ Pembebasan Ruang Instan 2 GB – 10 GB (Tanpa Hapus Chat & Aplikasi)

Buka aplikasi File Manager (Pengelola File) bawaan HP → masuk ke Penyimpanan Internal → Android → media → com.whatsapp → WhatsApp → Databases. Hapus semua file msgstore-YYYY-MM-DD.1.db.crypt14 yang memiliki tanggal di namanya, dan sisakan satu file msgstore.db.crypt14. Trik ini langsung membebaskan 1 GB hingga 8 GB ruang memori tanpa menghilangkan satu pun chat WhatsApp Anda.

Anatomi Penyimpanan "File Lainnya" yang Membuat Memori HP Penuh

Diagram di bawah ini memetakan porsi ruang tersembunyi yang paling sering memakan memori internal tanpa disadari pengguna:

Metode 1: Menghapus Arsip Database Cadangan Lama WhatsApp (msgstore)

Setiap pukul 02.00 dini hari, WhatsApp secara otomatis menggandakan seluruh database percakapan Anda ke penyimpanan internal ponsel hingga menyimpan 7 file cadangan terakhir. Jika ukuran database chat Anda mencapai 600 MB, maka folder ini diam-diam memakan lebih dari 4,2 GB ruang memori.

Langkah Pembersihan Folder Databases WhatsApp:

  1. Buka aplikasi File Manager (Pengelola File / File Saya) di ponsel Anda.
  2. Ketuk ikon titik tiga di pojok kanan atas, lalu aktifkan opsi Tampilkan file tersembunyi (Show hidden files).
  3. Telusuri jalur folder berikut sesuai versi Android Anda:
    • Android 11 ke atas: Penyimpanan Internal → Android → media → com.whatsapp → WhatsApp → Databases
    • Android 10 ke bawah: Penyimpanan Internal → WhatsApp → Databases
  4. Di dalam folder tersebut, Anda akan melihat beberapa file bernama msgstore-2026-XX-XX.1.db.crypt14 dan satu file utama bernama msgstore.db.crypt14.
  5. Tandai dan hapus seluruh file yang memiliki tanggal di namanya, lalu biarkan satu file msgstore.db.crypt14 tetap utuh sebagai cadangan lokal terbaru.

Metode 2: Membersihkan Folder "Sent" & Media Berulang di WhatsApp

Setiap kali Anda mengirim foto, video, atau dokumen ke grup maupun kontak WhatsApp, sistem membuat salinan duplikat di dalam folder khusus bernama Sent. Artinya, satu video berdurasi 3 menit yang Anda rekam dan kirim lewat WhatsApp akan memakan memori dua kali lipat.

Cara Menguras Media Duplikat Tanpa Merusak Galeri Utama:

  1. Buka aplikasi WhatsApp → Titik Tiga (⋮) → Setelan → Penyimpanan dan Data.
  2. Ketuk menu Kelola Penyimpanan (Manage Storage).
  3. Pilih daftar Lebih besar dari 5 MB dan Diteruskan berkali-kali, lalu centang video atau dokumen besar yang sudah tidak diperlukan dan ketuk ikon Hapus.
  4. Untuk membersihkan folder Sent secara tuntas, buka kembali File Manager → Android → media → com.whatsapp → WhatsApp → Media.
  5. Buka folder WhatsApp Video → Sent dan WhatsApp Images → Sent, lalu hapus salinan file kiriman lama di dalamnya. File asli yang ada di kamera/galeri Anda tidak akan ikut terhapus.
  6. Terakhir, kembali ke menu Penyimpanan dan Data di WhatsApp, lalu pada bagian Unduh otomatis media, hilangkan semua centang (Foto, Audio, Video, Dokumen) baik saat menggunakan data seluler maupun Wi-Fi agar grup WhatsApp tidak lagi memenuhi memori secara otomatis.

Metode 3: Mengosongkan Tempat Sampah Tersembunyi (Baru Dihapus) di 3 Lokasi

Inilah alasan utama mengapa memori HP tetap penuh padahal Anda sudah menghapus ratusan foto dan video: sistem Android modern tidak langsung menghapus file dari chip penyimpanan, melainkan memindahkannya ke ruang karantina (Trash / Recycle Bin) selama 30 hingga 60 hari.

Kosongkan Ketiga Lokasi Tempat Sampah Berikut:

  1. Aplikasi Galeri Bawaan HP: Buka Galeri → tab Album → gulir ke paling bawah → ketuk Baru Dihapus (Sampah / Trash) → pilih Kosongkan Semua.
  2. Aplikasi File Manager Bawaan: Buka File Manager → menu Garis Tiga / Pengaturan → pilih Sampah (Recycle Bin) → ketuk Hapus Permanen.
  3. Aplikasi Google Photos (Foto) & Files by Google: Buka aplikasi Google Foto → Galeri (Library) → Sampah (Trash) → Kosongkan Sampah.

Metode 4: Menguras Cache Video TikTok, Telegram, CapCut, dan Instagram

Meskipun ukuran aplikasi TikTok atau Telegram di Play Store hanya sekitar 80 MB, setelah digunakan menonton video selama beberapa minggu, ukuran datanya di pengaturan HP bisa membengkak menjadi 5 GB hingga 15 GB.

1. Membersihkan Cache di Dalam Aplikasi TikTok (Tanpa Logout)

  • Buka aplikasi TikTok → Profil → ikon Garis Tiga di kanan atas → Pengaturan dan Privasi.
  • Gulir ke bagian bawah dan ketuk Kosongkan Ruang (Free up space).
  • Ketuk tombol Bersihkan pada baris Cache dan Unduhan. Anda juga dapat menghapus Draft video yang sudah tidak diedit lagi karena 1 draft video beresolusi HD dapat memakan 200 MB – 800 MB.

2. Mengatur Batas Penyimpanan Otomatis di Telegram

  • Buka aplikasi Telegram → Garis Tiga di kiri atas → Pengaturan (Settings) → Data dan Penyimpanan.
  • Ketuk Penggunaan Penyimpanan (Storage Usage) → Bersihkan Cache.
  • Geser pengatur Ukuran Cache Maksimal (Maximum Cache Size) ke angka paling kecil, yaitu 5 GB, dan atur penghapusan otomatis media yang tidak diakses menjadi 1 Minggu.

3. Menghapus Data Situs yang Membengkak di Google Chrome

  • Buka Google Chrome → Titik Tiga → Setelan → Setelan Situs → Data yang tersimpan (Data stored) (atau Semua Situs → urutkan berdasarkan Data yang digunakan).
  • Ketuk tombol Hapus semua data untuk membuang penyimpanan lokal situs web yang menumpuk hingga ratusan megabyte.

Metode 5: Menghapus Folder Tersembunyi .thumbnails di DCIM

Setiap kali Anda membuka aplikasi Galeri, Android membuat salinan gambar ukuran kecil di dalam folder tersembunyi bernama .thumbnails agar pengguliran foto terasa cepat. Namun seiring waktu, indeks pratinjau ini tetap menyimpan rekaman ribuan foto lama yang sudah lama Anda hapus sehingga ukurannya bisa menembus 2 GB – 5 GB.

  1. Buka File Manager dan pastikan opsi Tampilkan file tersembunyi sudah aktif.
  2. Masuk ke Penyimpanan Internal → DCIM → .thumbnails (atau Pictures → .thumbnails).
  3. Hapus seluruh isi file di dalam folder .thumbnails tersebut (termasuk file besar bernama .thumbdata4--...). Langkah ini 100% aman dan tidak menghapus foto asli di kamera Anda.

Pertanyaan yang Sering Diajukan (FAQ)

1. Apakah menghapus file msgstore bertanggal di folder Databases WhatsApp akan menghapus chat saat ini?

Tidak. Seluruh percakapan aktif yang tampil di aplikasi WhatsApp Anda tersimpan di partisi sistem aplikasi dan diwakili oleh file cadangan terbaru msgstore.db.crypt14 (tanpa tanggal). File yang mencantumkan tanggal di namanya hanyalah salinan cadangan hari-hari sebelumnya yang aman dihapus untuk menghemat memori.

2. Mengapa kategori "Lainnya" (Other / System Data) di penyimpanan HP bisa mencapai puluhan GB?

Kategori Lainnya merupakan wadah bagi semua berkas yang tidak memiliki ekstensi gambar, video, audio, atau dokumen standar. Isi utamanya adalah file enkripsi database WhatsApp (.crypt14), potongan cache streaming video TikTok dan Telegram, indeks .thumbdata, serta berkas yang masih tertahan di folder Sampah (Baru Dihapus).

3. Apa beda Hapus Cache dan Hapus Data di Pengaturan Aplikasi Android?

Hapus Cache (Clear Cache) hanya membuang file sementara sehingga akun Anda tetap login dan riwayat chat tidak hilang. Sebaliknya, Hapus Data (Clear Data / Clear Storage) akan mengembalikan aplikasi ke kondisi awal seperti baru diunduh dari Play Store dan menghapus seluruh data login serta file lokal aplikasi tersebut.
